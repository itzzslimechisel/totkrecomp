## Architecture (what exists and works)
- Route: x86-64 via dynarmic (azahar fork, 0BSD, pinned a466015) running UNREWRITTEN NSOs, identity-mapped memory at 0x8_0000_0000, host traps for guest->host calls.
- Platform layer games/totk/runtime/platform (mem/thread/time/fault/fs), cpu_backend.h + cpu_dynarmic.cpp, loader_win.c, jit_glue.c, hle_nvn under JIT with traps generated by tools/windows/gen_nvn_traps.py, null backend gfx/nvn/nvn_null.c, Vulkan backend gfx/nvn/nvn_vk*.c (SDL3 window via frontend_win.c, SPIR-V via totk_xlate --target spirv, CPU ASTC decode), WASAPI audio, SDL3 input/gamepad, import_game.py (NSP/XCI+keys -> ExeFS/RomFS, verified hashes), build_windows.py (packaging), ImGui launcher (Play, Game files, Settings, Saves, Controls) with bundled embeddable Python.
- Versions shipped: 1.0.0, 1.1.1, 1.2.0, 1.4.3 (1.1.1/1.2.0 are new Windows-only ports of patch sites). 1.4.2 NOT supported (all modules differ; ~143 hardcoded offsets).
- Status: boots and renders prologue on Vulkan; audio live; input wired but untested by hand.
